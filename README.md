# LeVerse

LeVerse ist ein kleiner Launcher für Windows 10 und 11. Er installiert und aktualisiert meine Apps und meldet neue Versionen. Dieses Repository enthält nur die fertigen Downloads und den Katalog, keinen Quellcode.

## Herunterladen

**[LeVerse.exe herunterladen](https://github.com/LemeSrc/leverse-releases/releases/latest/download/LeVerse.exe)** (etwa 2 MB)

Einfach starten. LeVerse richtet sich selbst ein und braucht keine Administrator-Rechte.

## Die Windows-Warnung beim ersten Start

Die Programme sind nicht kostenpflichtig signiert. Windows zeigt deshalb beim ersten Start „Der Computer wurde durch Windows geschützt“:

1. Auf **Weitere Informationen** klicken.
2. Auf **Trotzdem ausführen** klicken.

Jeder Download wird von LeVerse vor der Installation anhand seiner Prüfsumme kontrolliert.

## Was LeVerse anbietet

| App | Wofür | Hinweis |
|---|---|---|
| Flowstate | Razer-Geräte ohne Konto einstellen | Beta, getestet mit Viper Ultimate und BlackShark V2 Pro |
| SkyMail | E-Mail für mehrere Konten | |
| SkyMail für Android | Dieselbe Mail-App auf dem Handy | Kommt per QR-Code aufs Handy und meldet neue Versionen selbst |

## LeVerse entfernen

Unter Windows-Einstellungen › Apps › Installierte Apps. Mit LeVerse installierte Apps bleiben dabei erhalten.

Nutzung auf eigene Gefahr und ohne Gewähr.
